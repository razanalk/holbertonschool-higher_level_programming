The ``add_integer`` function
============================

    >>> add_integer(1, 2)

Using negative numbers:

    >>> add_integer(100, -2)

Using default value:

    >>> add_integer(2)

Using floats:

    >>> add_integer(100.3, -2)

Float conversion:

    >>> add_integer(4.8, 1.2)
