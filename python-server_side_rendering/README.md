# Python - Server-Side Rendering

This project introduces the concepts of Server-Side Rendering (SSR) using Python and Flask.

## Description

Server-Side Rendering is a technique where web pages are generated on the server and then sent to the client as fully formed HTML.

In this project, I will learn how to:

- Create dynamic web pages using Python and Flask.
- Use the Jinja templating engine.
- Create and work with HTML templates.
- Insert dynamic data into HTML pages.
- Read data from different sources such as JSON, CSV, and SQLite.
- Handle user input and dynamic content.

## Learning Objectives

By completing this project, I will be able to:

- Understand Server-Side Rendering.
- Understand the difference between Server-Side Rendering and Client-Side Rendering.
- Build web applications using Flask.
- Use Jinja templates to generate dynamic HTML.
- Work with dynamic data in web applications.
- Read and display data from JSON and CSV files.
- Work with SQLite databases.
- Handle user input and dynamic content.

## Requirements

- Python 3
- Flask
- Jinja2
