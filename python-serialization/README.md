# Python - Serialization

This project introduces the fundamentals of serialization and deserialization in Python. It covers how Python objects can be converted into different formats for storage or transmission and then reconstructed back into their original form.

## Learning Objectives

By completing this project, I learned how to:

- Serialize and deserialize Python objects.
- Work with JSON, CSV, and XML formats.
- Save and load data from files.
- Use Python modules such as `json`, `pickle`, `csv`, and `xml`.
- Handle custom object serialization.

## Tasks

- Basic JSON serialization
- Pickling custom classes
- CSV to JSON conversion
- XML serialization and deserialization
