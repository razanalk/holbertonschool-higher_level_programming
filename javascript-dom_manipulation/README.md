# JavaScript - DOM Manipulation

This project includes JavaScript scripts that demonstrate different techniques for manipulating the DOM.

## Tasks

- **0-script.js**: Changes the header text color to red
- **1-script.js**: Changes the header text color to red when the user clicks
- **2-script.js**: Adds the `red` class to the header when clicked
- **3-script.js**: Switches the header class between `red` and `green`
- **4-script.js**: Adds a new `li` element to a list when clicked
- **5-script.js**: Changes the header text when the user clicks
- **6-script.js**: Retrieves and displays a Star Wars character name
- **7-script.js**: Retrieves and displays a list of Star Wars movie titles
- **8-script.js**: Retrieves and displays the translation of "hello"
